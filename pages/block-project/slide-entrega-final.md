# Preparação

#### **Pré-requisitos para fazer a apresentação do projeto de bloco**

<br/>

<div class="[&_table]:w-full text-13px leading-tight [&_td]:py-2 [&_th]:py-3">

| # | Pré-requisito |
| --- | --- |
| 1 | O aluno deve instalar e configurar o seu sistema agêntico na sua máquina do laboratório |
| 2 | O aluno deve mostrar ao professor o dado estruturado (ex.: tabela, arquivo etc.) |
| 3 | O aluno deve mostrar ao professor o dado não estruturado (ex.: markdown, PDF etc.) |
| 4 | O aluno deve mostrar ao professor o workflow do n8n e o gatilho em execução (Telegram, chatbot web etc.) |
| 5 | O aluno deve usar duas perguntas de exemplo (estruturada e não estruturada) para mostrar o sistema agêntico em funcionamento |
| 6 | O professor irá fornecer duas novas perguntas de exemplo (estruturada e não estruturada) para o aluno executar no sistema agêntico |

# Apresentação

#### **Pontos principais para a apresentação**

<br/>

| # | Ponto |
| --- | --- |
| 1 | Apresentação de 4 a 5 minutos. Apresentações com menos de 4 minutos serão desconsideradas |
| 2 | A apresentação deve ser para o professor e os colegas |
| 3 | Além dos slides do projeto, incluir um ou dois slides com as duas perguntas de exemplo e suas respostas |
| 4 | Slides com tamanho de fonte grande |
| 5 | Todos os apontamentos de feedback dos TPs anteriores resolvidos, inclusive os vídeos no YouTube de cada TP |
